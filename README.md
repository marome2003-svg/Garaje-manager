# 🚗 Garage Manager

Proyecto personal para aprender **Python** desde cero desarrollando una aplicación de gestión de vehículos.

El objetivo no es solo crear un programa funcional, sino aprender de forma práctica las herramientas y tecnologías que utiliza un desarrollador profesional.

---

## 📖 Sobre el proyecto

Garage Manager será una aplicación que irá creciendo poco a poco.

Comenzará siendo un programa sencillo por consola y evolucionará hasta convertirse en una aplicación completa con base de datos e interfaz gráfica.

Cada nueva versión añadirá funcionalidades y servirá para aprender nuevos conceptos de programación.

---

## 🎯 Objetivos de aprendizaje

A lo largo del desarrollo iré aprendiendo:

- Variables y tipos de datos
- Condicionales
- Bucles
- Funciones
- Listas, tuplas y diccionarios
- Programación orientada a objetos
- Manejo de archivos
- SQLite
- Git y GitHub
- Buenas prácticas de programación

---

## 🛠️ Tecnologías
